# Vivahasuthra

Vivahasuthra is a wedding planning and event management web application developed to help users organize weddings and related events efficiently.

## Features
- User Registration and Login
- Wedding Event Planning
- Vendor Management
- Venue Selection
- Event Scheduling
- Budget Tracking

## Tech Stack
- React.js
- Node.js
- Express.js
- JavaScript
- HTML5
- CSS3

## Project Structure
```text
vivahasuthra/
├── client/
├── event-manager/
├── package.json
├── package-lock.json
├── .gitignore
└── README.md
```

## Installation and Setup

1. Clone the repository
```bash
git clone https://github.com/Lakshmiprasanna200/vivahasuthra-.git
```

2. Navigate to the project folder
```bash
cd vivahasuthra-
```

3. Install dependencies
```bash
npm install
```

4. Start the application
```bash
npm start
```
